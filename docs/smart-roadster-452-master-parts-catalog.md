# Smart Roadster 452 master parts catalog

## Status and usage

This is the first structured master list for all 452 body styles:

- `R` = standard Roadster
- `C` = Roadster Coupé
- `B` = BRABUS Roadster/Coupé
- `S` = special edition or market-specific; verify individually

An empty OEM number is intentional. It means the number must be resolved from
the Mercedes/smart EPC or a VIN-matched supplier record; it is not permission
to guess. Part numbers and supersessions can differ by market, build date,
option code, left/right-hand drive and BRABUS equipment.


## Part-number resolution workflow

1. Record the vehicle VIN, build date, market and body style.
2. Locate the component group in EPC or an equivalent VIN-driven catalogue.
3. Capture the complete OE number, diagram position and supersession chain.
4. Compare the number with the installed part label and connector/measurement.
5. Add aftermarket numbers only when the supplier explicitly cross-references
   the OE number and application.
6. Mark used, reconditioned, modified and BRABUS-only parts separately.
7. Record source URL, date and confidence.
